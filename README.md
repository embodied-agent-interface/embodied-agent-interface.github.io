# embodied-agent-eval.github.io
This is the project website for the paper "Embodied Agent Interface: Benchmarking LLMs for Embodied Decision Making".

Live site: https://embodied-agent-interface.github.io/

Embodied Agent Interface (EAI) is an LLM agent benchmark for embodied decision making, accepted as an Oral at the NeurIPS 2024 Datasets and Benchmarks Track. It evaluates Large Language Models on four ability modules (goal interpretation, subgoal decomposition, action sequencing, and transition modeling) in the VirtualHome and BEHAVIOR simulators, with fine-grained error metrics such as hallucination errors, affordance errors, and planning errors.
